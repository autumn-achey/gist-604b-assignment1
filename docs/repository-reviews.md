## Repository 1

**Repository Name:**  Gods Eye View
**Link:**  https://github.com/bilawalsidhu/gods-eye-view

### Purpose
What does this project do?
This project joins public signals into one globe, which is accessible to anyone. You can move between a global image and individual aircrafts, ships, or streets and this runs locally in your browser. You can add your own data sources as well. It has many uses including weather, satellite, coordinate location searches, and more. It is nicknamed a "spy-satellite simulator".

### Repository Structure
What folders or files stand out?
 The LICENSE file, as it is laveled as featuring the Nepal flood incident scene. SECURITY is also interesting as it says "keep camera routes reachable behind a reverse proxy"

### Documentation
How helpful is the README?
The README is very helpful as it includes an extensive overview of this project and what can be done with it.

### Activity
Is the repository actively maintained?
Yes. Some files and folders have been updated within an hour of me viewing it.

### Key Observation
One thing this project does well.
This project does a great job at pulling people in. The name catches the eye and the creator makes use of lots of imagery that catches the eye as well. This project also takes something that could be seen as "risky" and makes it available to everyone, further pulling in an audience.

## Repository 3

**Link:**  https://github.com/OSGeo/gdal

### Purpose
What does this project do?
This project is an informational regarding GDAL and includes various resources associated with the program. GDAL is "an open source MIT licensed translator library for raster and vector geospatial data formats."

### Repository Structure
What folders or files stand out?
This repository has many folders and files listed, but the ones labeled GUIDE stand out the most. Making guides easily accessible to the readers is a huge plus in my opinion.

### Documentation
How helpful is the README?
The README includes mostly links to folders or other sites that have information on GDAL. I wish there was more information regarding the actual program rather than just out sourced links.

### Activity
Is the repository actively maintained?
Yes, last updated 4 days ago.

### Key Observation
One thing this project does well.
This project includes lots of links to information on just about anything a person using GDAL could need. It has download instructions, bug tracker, and more.

## Reflection
Open source projects have a few things in common when it comes to organization. They all include a README file which generally contains project explanation and links to other files within the repository. They also almost all include contribution information, security features, and code of conducts.
